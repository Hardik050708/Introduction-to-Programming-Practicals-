# Practical 10 - Viva Answers

**Question 1: Indexing versus slicing?**

Indexing selects one character; slicing selects a substring or stepped sequence.

**Question 2: How does negative string indexing work?**

-1 selects the last character and more negative indices move toward the start.

**Question 3: find() versus index()?**

Both locate a substring; find returns -1 when absent, while index raises ValueError.

**Question 4: Why use strip()?**

It removes unwanted whitespace from the beginning and end of text.

**Question 5: How do split() and join() work together?**

split turns a string into parts and join combines string parts using a separator.

**Question 6: What is tokenization?**

It divides text into units such as words or subwords.

**Question 7: How are strings used in NLP preprocessing?**

They are normalized, cleaned, split into tokens, and analyzed.

**Question 8: Why are strings immutable?**

Python defines strings as fixed character sequences; editing creates a new string.

**Question 9: What are validation methods?**

Methods such as isdigit, isalpha, and isalnum test the characters in a nonempty string.

**Question 10: How do string operations help cybersecurity and AI?**

They support log parsing, password checks, identifier masking, and text preparation.
