# Practical 4 - Viva Answers

**Question 1: for versus while?**

for iterates over an iterable; while repeats as long as a condition remains true.

**Question 2: How does range() work?**

range(start, stop, step) produces integers up to but excluding stop.

**Question 3: What is an accumulator?**

It stores a running result such as a total or product.

**Question 4: Why use nested loops?**

They process combinations, matrix cells, or repeated pattern rows.

**Question 5: How is factorial calculated?**

Multiply integers from 1 through n, starting with 1; 0! is also 1.

**Question 6: How does iterative Fibonacci work?**

Keep two consecutive values and repeatedly update them to b and a + b.

**Question 7: How can prime checking be optimized?**

Test possible divisors only up to the integer square root of the number.

**Question 8: How does a loop check a numeric palindrome?**

Reverse digits using remainder and integer division, then compare with the original.

**Question 9: Entry-controlled versus exit-controlled loops?**

Entry-controlled loops test first; exit-controlled loops run once before testing; Python for and while are entry-controlled.

**Question 10: Why are loops useful in automation?**

They repeat operations across records or until a stopping condition is reached.
