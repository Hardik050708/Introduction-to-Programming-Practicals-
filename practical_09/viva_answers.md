# Practical 9 - Viva Answers

**Question 1: What is the purpose of functions?**

They group reusable operations into named units.

**Question 2: Parameters versus arguments?**

Parameters are names in a definition; arguments are values supplied in a call.

**Question 3: What does return do?**

It ends a function call and sends a value back to the caller.

**Question 4: Built-in versus user-defined functions?**

Built-ins such as len are provided by Python; user-defined functions are written with def.

**Question 5: What is recursion?**

It is a function solving a problem by calling itself on a smaller subproblem.

**Question 6: Why is a base case necessary?**

It stops recursive calls and provides the simplest result.

**Question 7: What is variable scope?**

It is the region where a name can be accessed; function assignments are local unless declared global or nonlocal.

**Question 8: What are default arguments?**

They supply parameter values when a call omits those arguments.

**Question 9: How do functions improve modularity?**

They separate responsibilities so each part can be reused, understood, and tested.

**Question 10: Where is recursion used?**

It is useful in tree traversal, directory walking, and divide-and-conquer algorithms.
