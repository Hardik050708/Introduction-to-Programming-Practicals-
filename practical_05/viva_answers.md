# Practical 5 - Viva Answers

**Question 1: What does break do?**

It immediately exits the innermost enclosing loop.

**Question 2: continue versus break?**

continue skips the remaining current iteration; break ends the loop.

**Question 3: When is pass used?**

It supplies a no-op placeholder where Python requires a statement.

**Question 4: How does break improve a search?**

It stops checking remaining elements once the desired match is found.

**Question 5: Why use continue in cleaning data?**

It skips invalid records while processing the remaining records.

**Question 6: What is a sentinel-controlled loop?**

It reads values until a special stopping value, such as zero, appears.

**Question 7: Can nested loops use break?**

Yes, but break exits only the innermost loop containing it.

**Question 8: How does a retry system work?**

Count failures in a loop and stop on success or when the attempt limit is reached.

**Question 9: What if pass is removed from an empty block?**

The block has no required statement and raises an indentation or syntax error.

**Question 10: Where are loop controls useful?**

They support login retries, searches, input filtering, and emergency stopping.
