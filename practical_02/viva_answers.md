# Practical 2 - Viva Answers

**Question 1: What does input() do?**

It reads a line from the user and returns it as a string.

**Question 2: Why convert numeric input?**

Conversion makes arithmetic numeric instead of joining text or raising type errors.

**Question 3: print() versus f-strings?**

print() displays objects; an f-string builds formatted text that print() can display.

**Question 4: What are the arithmetic operators?**

+ adds, - subtracts, * multiplies, / divides, // floors, % gives the remainder, and ** raises a power.

**Question 5: What is operator precedence?**

It determines evaluation order when an expression combines operators.

**Question 6: How do /, //, %, and ** differ?**

/ gives division, // floors the quotient, % gives the remainder, and ** computes a power.

**Question 7: How can one line hold multiple inputs?**

Split the line and convert values, for example a, b = map(int, input().split()).

**Question 8: What happens when arithmetic uses strings?**

+ joins strings, * with an integer repeats a string, and unsupported combinations raise TypeError.

**Question 9: What do parentheses change?**

They group expressions so the grouped operation is evaluated first.

**Question 10: How can division by zero be prevented?**

Check that the denominator is nonzero before division, or catch ZeroDivisionError.
